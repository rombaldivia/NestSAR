## Remaining input dependence: actor ordering

`ordered_raw()` currently sorts people by `sum(abs(raw_coordinates))`. That is
camera-dependent, even after the padding and scale correction. A deterministic
synthetic check with two stationary actors and a constant camera translation
changed the selected primary actor and the normalized tokens:

```python
import numpy as np
from experiments.nestsar_sm_all_t16.preprocessing_corrected import ordered_raw, features
x = np.ones((32, 2, 25, 3), np.float32)
x[..., 2] = 3
x[:, 0, :, 0] = 1 + np.linspace(0, .2, 25)
x[:, 1, :, 0] = 2 + np.linspace(0, .2, 25)
y = x.copy()
y[..., 0] -= 5
a = ordered_raw(x, layout="TMVC")
b = ordered_raw(y, layout="TMVC")
assert a[0, 0, 0, 0] == 2
assert b[0, 0, 0, 0] + 5 == 1
assert not np.allclose(features(a), features(b))
```

Maximum token difference in this check was 4.904291. This demonstrates input
dependence, not an accuracy loss or a measured benefit from changing the order.
The ordering rule has not been changed in the runtime-recovery branch. Test a
clip-level order based on validity and valid motion energy (stable tie-breaking),
or an actor-swap training ablation, before changing the verified baseline. Any
new ordering needs a new cache version and a separate retraining output directory.

## Next accuracy experiments

1. Reproduce the current SM-ALL baseline on both protocols with the shared cache;
   save per-sample predictions, confusion matrices, per-class recall and top-five
   coverage. These aggregate results alone cannot rank weak action classes.
2. Test translation-independent actor ordering with all other settings held
   fixed. Verify unchanged 16-token shape, valid-mask behavior and full transition
   coverage, then measure accuracy across matched seeds.
3. The current augmentation is only ±8-degree yaw and ±1-frame segment jitter.
   Test modestly stronger, label-preserving variation and stochastic pose
   representatives inside segments. Rebuild all affected motion summaries from
   the augmented skeleton; do not discard transitions or change inference shape.
4. Reproduce a CD-Former teacher using its own preprocessing and the matching
   protocol's training split. Verify sample-ID alignment before logit distillation.
   The teacher is training-only; inference remains the SM-ALL student. Knowledge
   distillation is established, but its benefit here has not been measured. [Distillation paper](https://arxiv.org/abs/1503.02531).
5. If confusion analysis shows persistent close action pairs, compare a
   training-only contrastive refinement objective against CE/KD alone. FR-Head
   provides evidence for skeleton ambiguity reduction on GCN backbones; adapting
   its principle to SM-ALL is an experiment, not a proven result. [FR-Head paper](https://arxiv.org/abs/2303.03729).

Use the same protocol splits, seed, effective batch, schedule and patience 5
after warm-up. Select ablations using training-only development data and avoid
repeated tuning on the official evaluation split. No numeric accuracy gain is
guaranteed by these suggestions.
